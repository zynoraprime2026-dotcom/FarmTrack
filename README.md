# FarmTrack

Farm records & money for smallholders — livestock, breeding, income/expenses, reports.

Single-file offline-first app (`index.html`). Works from any static host; data is stored in the browser (localStorage) so it keeps working with no connection. Add to Home Screen to install as an app.

## Run locally
Open `index.html` in a browser, or serve the folder.

## Deploy
Drag the folder into https://vercel.com/new (or any static host).
